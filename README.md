# 🎟️ VirtualTicketing

## 🧩 Overview
VirtualTicketing is a web application developed using **ASP.NET Core MVC** and **PostgreSQL**.  
It allows users to browse events, purchase tickets, and confirm orders through a visually appealing **Neon Future** themed interface.

---

## 🚀 Features
- Browse events by category
- Add tickets to cart and review purchase details
- Confirm ticket purchases (with a confetti animation 🎉)
- PostgreSQL integration for event and purchase data
- Fully responsive, futuristic UI

---

## ⚙️ Technologies Used
- ASP.NET Core 8 MVC
- Entity Framework Core
- PostgreSQL
- Bootstrap 5
- CSS (Custom Neon Future Theme)
- JetBrains Rider IDE

---

## 🧰 Setup Instructions
1. Clone this repository
2. Open the project in **JetBrains Rider** or **Visual Studio**
3. Configure your `appsettings.json` file with your PostgreSQL connection string, e.g.
   ```json
   "ConnectionStrings": {
       "DefaultConnection": "Host=localhost;Database=VirtualTicketingDB;Username=postgres;Password=yourpassword"
   }
